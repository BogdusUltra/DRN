# Инструкция по запуску узла сети DRN (Агента)

Эта инструкция описывает полный цикл развертывания агента DRN на новой машине (Raspberry Pi, Ubuntu VM, и т.д.).

## 1. Установка

Агент устанавливается как стандартный Python-пакет прямо из репозитория.

```bash
# Для современных систем (Ubuntu 23+, Debian 12+) может потребоваться флаг --break-system-packages
pip3 install git+https://github.com/BogdusUltra/DRN.git#subdirectory=drn-agent --break-system-packages
```

При обновлении добавьте флаги `--upgrade --force-reinstall`.

## 2. Инициализация (Первый запуск)

Перед запуском агента нужно сгенерировать криптографические ключи и задать пароль, который будет использоваться Оркестратором для подключения к этой машине.

```bash
drn init --name "MyMachine_1" --password "secret_password"
```

**Опциональные параметры:**
* `--beacon-interval N` — задает частоту (в секундах), с которой машина отправляет UDP-маячок в сеть (по умолчанию: 2).

*Пример:*
```bash
drn init --name "Rpi_Camera" --password "1234" --beacon-interval 5
```

Команда `drn init` создаст скрытую папку `~/.drn_agent`, где будут храниться ключи (public/private), хэш пароля и белый список доверенных Оркестраторов.

## 3. Запуск демона

После инициализации агент запускается в фоновом режиме:

```bash
drn start
```

Агент отвязывается от консоли, поэтому вы можете закрыть терминал. Агент начнет слушать команды по TCP (порт 50001) и вещать маячок по UDP (порт 50000).

## 4. Остановка и Сброс

Если вам нужно остановить фоновый процесс:
```bash
drn stop
```

Если вы хотите полностью стереть данные агента с машины (например, чтобы передать машину в другой проект) и удалить все ключи:
```bash
drn reset
```

## 5. Справка

Вы всегда можете посмотреть доступные команды и их параметры, используя флаг `--help` или `-h`:
```bash
drn --help
drn init --help
```
