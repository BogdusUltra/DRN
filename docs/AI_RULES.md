# Правила работы ИИ-Ассистента (Antigravity) для проекта DRN

1. **Документирование на лету:** После каждого уточнения архитектурных решений, изменения логики или принятия новых концепций в чате — ИИ обязан **сразу же** синтезировать суть (конспект) и сохранять её в соответствующий markdown-файл в папке `docs/`. Полагаться только на историю чата запрещено.
2. **План перед кодом:** Перед написанием или изменением любого кода ИИ обязан выдать краткую спецификацию (какие библиотеки, какие классы, функции и логика работы) и дождаться одобрения пользователя.
3. **Контекст пользователя:** Использовать актуальные данные пользователя при генерации команд. 
   - Официальный репозиторий проекта: `https://github.com/BogdusUltra/DRN`
